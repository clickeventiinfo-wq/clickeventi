# Click Eventi

Sito di Click Eventi — marketplace per trovare professionisti per eventi.

- `/` : sito lato cliente
- `/?pannello` : demo del pannello fornitore

## Comandi
- `npm install` — installa le dipendenze
- `npm run dev` — anteprima locale
- `npm run build` — crea la versione da pubblicare
